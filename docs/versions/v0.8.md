# v0.7 / v0.8: the working base

**Date:** 2025-10-20 to 2025-10-22
**Versions:** server `0.8`, client `0.7`

The first version that ran end to end: a server, a client that connects to it,
and a page showing who is connected.

## Delivered

- Server rewritten on `asyncio`, one coroutine per connected client
- Client that connects to the server and identifies itself
- Commands loaded from a folder, each command a `def function():` in its own file
- `list` showing every known client, with `ip:port` when it is online
- Simple web page showing the client data
- `start_all.bat` starting the server and the client together

## Left as known limitations

- Server and client duplicated a lot of code
- Messages had no framing, so two messages in one read could be lost
- Only the client could start a conversation
- A dropped connection could make the client spin instead of reconnecting
