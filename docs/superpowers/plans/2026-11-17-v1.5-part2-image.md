# v1.5 Part 2: The image and the compose file Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docker compose up -d --build` runs the server in a container: healthy, its data in `./server-data`, its console through `docker attach`, stopped cleanly by `docker compose stop`, and an image that never holds a config, database or key. A CI job builds and runs it on every push.

**Architecture:** a one stage `Dockerfile` on `python:3.13-slim` copies `requirements.txt`, `shared/` and `server/` only, runs as uid 1000 with `PYHOME_DATA=/data` (Part 1) and `server/healthcheck.py` as its health check. `.dockerignore` starts with `*` and lets the server back in. `docker-compose.yml` publishes 50000, 50001 and 50002/udp, mounts `./server-data`, sets `TZ`, a fixed hostname and a terminal; `docker-compose.host.yml` puts it on the host's network for discovery on Linux. `tests/test_docker.py` checks all of it without Docker; `tests/test_docker_e2e.py` runs the real image, gated by `PYHOME_DOCKER_TESTS=1`, which the new `docker` job sets.

**Tech Stack:** Docker, Docker Compose 2.24 or newer (`!reset`, `!override`), Python 3.13 in the image. pytest.

**Spec:** `docs/v1.5-spec.md`, section "Part 2", as amended in Task 3.

**Verified:** built and run in a sandbox first. The image builds in about 12 s, 276 MB. Planted `config.json`, `pyhome.db`, `ca.key` and client configs never reached it. Under compose: healthy, `server-data/config.json` made from the example, found by **Hľadať servery**, a client from the checkout connected, `list` answered through `docker attach` and Ctrl+P Ctrl+Q left it running, `docker compose stop` took 0.5 s with code 0 and no WAL file, and after `up -d` it knew its client. TLS: `make_certs.py` inside the container named `PYHOME_ADDRESS`, the health check stayed healthy over HTTPS, and a client made through the launcher's api fetched the container's `ca.crt`, matched the fingerprint and connected `(TLS)`. With the host override a broadcast found it at the computer's own address. Found on the way: the base image already has the zone files (no apt); a certificate made inside named the random container id (now `hostname: pyhome`); `!reset` with a list empties it in an override, `!override` replaces it.

## Global Constraints

- Nothing but `requirements.txt`, `shared/`, `server/` and the server's example config reaches the build context.
- The container never runs as root.
- Every port the config uses is published; a changed port is changed in both.
- The Docker end to end test never builds from the working folder itself: it copies the repository and plants secrets in the copy.
- In a sandbox behind a proxy, the build gets `PYHOME_DOCKER_BUILD_ARGS="--network host"`; nothing about the proxy goes into the repository.
- Work happens on branch `claude/admiring-ptolemy-mfwswb`.

+def pattern_regex(pattern):
+    """A .dockerignore pattern as a regex: ** any folders, * and ? within one name."""
+    out = ""
+    i = 0
+    while i < len(pattern):
+        if pattern.startswith("**/", i):
+            out += "(?:.*/)?"
+            i += 3
+        elif pattern.startswith("**", i):
+            out += ".*"
+            i += 2
+        elif pattern[i] == "*":
+            out += "[^/]*"
+            i += 1
+        elif pattern[i] == "?":
+            out += "[^/]"
+            i += 1
+        else:
+            out += re.escape(pattern[i])
+            i += 1
+    return re.compile(out + r"\Z")

+"""Docker's health check: does the dashboard answer? Exit 0 when it does, 1 when it does not.
+
+It asks the server it runs next to, on 127.0.0.1, so with TLS the
+certificate is not checked: its names are the ones the house uses.
+"""
+import os
+import ssl
+import sys
+import urllib.request
+
+APP_DIR = os.path.dirname(os.path.abspath(__file__))
+sys.path.insert(0, os.path.dirname(APP_DIR))
+
+from shared import config  # noqa: E402
+
+
+def dashboard_url():
+    port = config.get_config("WEB_PORT", 50001)
+    scheme = "https" if config.get_config("TLS_CERT") else "http"
+    return f"{scheme}://127.0.0.1:{port}/"
+
+
+def check(url, timeout=4):
+    """True when url answers 200. Never through a proxy: it is this machine."""
+    context = ssl.create_default_context()
+    context.check_hostname = False
+    context.verify_mode = ssl.CERT_NONE
+    opener = urllib.request.build_opener(urllib.request.ProxyHandler({}), urllib.request.HTTPSHandler(context=context))
+    try:
+        with opener.open(url, timeout=timeout) as response:
+            return response.status == 200
+    except OSError as e:
+        print(f"{url}: {e}")
+        return False
+
+
+def main(argv):
+    config.init(APP_DIR, config.config_file_from_argv(argv), config.data_dir_from_env())
+    return 0 if check(dashboard_url()) else 1
+
+
+if __name__ == "__main__":
+    sys.exit(main(sys.argv))
