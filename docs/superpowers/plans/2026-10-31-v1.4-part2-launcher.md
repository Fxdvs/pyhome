# v1.4 Part 2: The desktop launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `launcher.pyw` opens one dark glass window on pywebview: the server and every client in a sidebar with status dots and ticks, the selected app's output with its colors and a command line into it, a form for a new or edited client and the server's settings, Stop that ends an app the way a person would, ticks and selection remembered, and a question before closing with apps running.

**Architecture:** `shared.console.interactive()` makes the apps print plain lines without a terminal; `shutdown` raises `ShutdownRequested` instead of a `SystemExit` inside asyncio, and the server stops uvicorn, ends client connections and closes the store in that order. `launcher/runner.py` runs one app with pipes and a numbered output buffer. `launcher/api.py` is every method the page calls, on `runner.py` and `core.py`, with `launcher/state.json`. `launcher/web/` is the page: `index.html`, plain `app.js` whose `backend` object is the only place that knows pywebview, `tailwind.css` with the theme tokens, and the committed `launcher.css` built by `launcher/build_css.py`. `launcher.pyw` only opens the window.

**Tech Stack:** Python 3.10+, pywebview 5 or newer, HTML, plain JavaScript, Tailwind CSS 4 (standalone CLI v4.1.11). pytest; Playwright and pywebview on Qt under Xvfb for the manual checks.

**Spec:** `docs/v1.4-spec.md`, section "Part 2: The desktop launcher", as amended in Task 5.

**Verified:** built in a scratch checkout first: 311 tests pass. The page was driven in Chromium against the real `Api` (a small HTTP bridge, not committed) with a real server and clients: run ticked, `list` typed into the server, a new client made in the form (id from the name, a wrong id refused with the reason, the token and certificates made by button, the client connected `(TLS)`), the server stopped cleanly, the close question. Then the real `launcher.pyw` window on pywebview 6.2.1 with Qt WebEngine under Xvfb: the page sees exactly the 20 public methods, apps run, closing with two apps running keeps the window open and asks, **Zastaviť a zavrieť** stops them and the process ends in 6.6 s with no app and no WAL file left. Found on the way, and covered: `shutdown` ended the apps with tracebacks; clients were dropped after the store was closed; `wait_for_enter()` would hang a launched app; a page call in flight at close kept the process alive forever; two polls at once showed lines twice; a sheet too transparent to read over the console.

## Global Constraints

- Apps started by hand in a console behave exactly as before; only without a terminal are prompts dropped.
- Everything the page calls returns plain JSON; nothing in `Api` is public except methods for the page (pywebview exposes every public attribute).
- The page loads nothing from the network.
- `launcher.css` is committed and must be built from the current sources; the hash in its first line ignores line endings.
- pywebview is not needed for the tests or the apps, only for `launcher.pyw`; it is imported inside `main()`.
- Texts in the window are Slovak, like the dashboard.
- Work happens on branch `claude/admiring-ptolemy-mfwswb`.

```diff
+"""One app run inside the launcher: started with pipes, its output kept, its input written.
+
+The app is the same `python app.py --config <file>` a console runs, but
+without a console window: stdout and stderr go into a buffer the page
+reads, and a line typed in the page goes to its stdin. The apps see no
+terminal, so they print plain lines and draw no prompt (shared.console).
+"""
+import collections
+import os
+import subprocess
+import threading
+import time
+
+# no console window for the app, on windows; elsewhere there is none anyway
+NO_WINDOW = getattr(subprocess, "CREATE_NO_WINDOW", 0)
+
+# lines kept per app; older ones are dropped
+LIMIT = 5000
+
+# Stop: shutdown and y, then terminate after STOP_GRACE seconds, then kill after KILL_AFTER more
+STOP_GRACE = 3
+KILL_AFTER = 5
+
+# the launcher's own lines in an app's output, colored like the apps color theirs
+GRAY = "\033[90m"
+RED = "\033[91m"
+BLUE = "\033[94m"
+RESET = "\033[0m"
+
+
+class Runner:
+    """An app the launcher can start, talk to and stop. Thread safe: the page calls it from many threads."""
+
+    def __init__(self, command, cwd, limit=LIMIT):
+        self.command = command
+        self.cwd = cwd
+        self.process = None
+        self.started_at = None
+        self._lines = collections.deque(maxlen=limit)
+        self._next = 1
+        self._lock = threading.Lock()
+        self._reader = None
+        # set by stop(), so an exit the launcher asked for is not shown as an error
+        self._stopping = False
+
+    # output
+
+    def _add(self, text):
+        with self._lock:
+            self._lines.append((self._next, text))
+            self._next += 1
+
+    def note(self, text, color=GRAY):
+        """A line from the launcher itself in the app's output."""
+        self._add(f"{color}{text}{RESET}")
+
+    def output(self, since=0):
+        """{"lines": [[number, text], ...] after line number since, "last": the newest number}."""
+        with self._lock:
+            lines = [[number, text] for number, text in self._lines if number > since]
+            return {"lines": lines, "last": self._next - 1}
+
+    # lifecycle
+
+    def is_running(self):
+        return self.process is not None and self.process.poll() is None
+
+    def status(self):
+        """{"state": running, stopped or exited, "code", "uptime" in seconds while running}.
+
+        exited means it ended on its own with an error; ended by Stop, or by
+        its own shutdown (code 0), it is stopped.
+        """
+        if self.process is None:
+            return {"state": "stopped", "code": None, "uptime": None}
+        code = self.process.poll()
+        if code is None:
+            return {"state": "running", "code": None, "uptime": round(time.time() - self.started_at)}
+        state = "stopped" if code == 0 or self._stopping else "exited"
+        return {"state": state, "code": code, "uptime": None}
+
+    def start(self):
+        """Start the app. False when it already runs or cannot be started (the reason is in its output)."""
+        if self.is_running():
+            return False
+        env = dict(os.environ, PYTHONUNBUFFERED="1", PYTHONIOENCODING="utf-8")
+        if self._next > 1:
+            self.note("─" * 12 + " znova spustené " + "─" * 12)
+        try:
+            self.process = subprocess.Popen(
+                self.command, cwd=self.cwd, env=env, creationflags=NO_WINDOW,
+                stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
+            )
+        except OSError as e:
+            self.process = None
+            self.note(f"Nedá sa spustiť: {e}", RED)
+            return False
+        self._stopping = False
+        self.started_at = time.time()
+        self._reader = threading.Thread(target=self._read, args=(self.process,), daemon=True)
+        self._reader.start()
+        return True
+
+    def _read(self, process):
+        # bytes, decoded here: a stray byte must not end the reading
+        for raw in iter(process.stdout.readline, b""):
+            self._add(raw.decode("utf-8", errors="replace").rstrip("\r\n"))
+        code = process.wait()
+        process.stdout.close()
+        if process.stdin:
+            try:
+                process.stdin.close()
+            except OSError:
+                pass
+        if self._stopping or code == 0:
+            self.note("Zastavené.")
+        else:
+            self.note(f"Skončilo s kódom {code}.", RED)
+
+    def _write(self, line):
+        try:
+            self.process.stdin.write((line + "\n").encode("utf-8"))
+            self.process.stdin.flush()
+            return True
+        except (OSError, ValueError, AttributeError):
+            # the app ended in the meantime, its stdin is gone
+            return False
+
+    def send(self, line):
+        """Type a line into the app, as in its own console. Shown in the output. False when it is not running."""
+        if not self.is_running():
+            return False
+        self._add(f"{BLUE}> {line}{RESET}")
+        return self._write(line)
+
+    def stop(self, grace=STOP_GRACE, kill_after=KILL_AFTER):
+        """End the app the way a person would: shutdown, y. Then terminate, then kill. Blocks until it ended."""
+        process = self.process
+        if process is None or process.poll() is not None:
+            return
+        self._stopping = True
+        self.note("Zastavujem...")
+        self._write("shutdown")
+        self._write("y")
+        try:
+            process.wait(timeout=grace)
+        except subprocess.TimeoutExpired:
+            process.terminate()
+            try:
+                process.wait(timeout=kill_after)
+            except subprocess.TimeoutExpired:
+                process.kill()
+                process.wait()
+        if self._reader is not None:
+            self._reader.join(timeout=2)
```

```diff
+  text = text.replace(/\r/g, "");
+  for (const match of text.matchAll(ESCAPE)) {
+    flush(text.slice(last, match.index));
+    last = match.index + match[0].length;
+    if (match[2] !== "m") continue;
+    for (const code of (match[1] || "0").split(";").map(Number)) {
+      if (code === 0) { color = null; bold = false; }
+      else if (code === 1) bold = true;
+      else if (code === 22) bold = false;
+      else if (code === 39) color = null;
+      else if (code >= 30 && code <= 37) color = ANSI_COLORS[code - 30];
+      else if (code === 90) color = "gray";
+      else if (code >= 91 && code <= 97) color = ANSI_COLORS[code - 90];
+    }
+  }
+  flush(text.slice(last));
+  return html;
+}
```

```diff
+"""Builds launcher/web/launcher.css from tailwind.css with Tailwind's standalone CLI.
+
+    py launcher/build_css.py path/to/tailwindcss.exe
+
+The CLI is one executable from https://github.com/tailwindlabs/tailwindcss/releases
+(tailwindcss-windows-x64.exe and so on), no Node needed. The built file is
+committed, so running the launcher needs no build. Its first line carries a
+hash of the sources, and a test fails when the sources changed without a rebuild.
+"""
+import hashlib
+import os
+import subprocess
+import sys
+
+WEB_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "web")
+SOURCES = ("tailwind.css", "index.html", "app.js")
+OUTPUT = os.path.join(WEB_DIR, "launcher.css")
+
+
+def sources_hash(web_dir=WEB_DIR):
+    """SHA-256 of the sources, line endings normalized: a windows checkout must hash the same."""
+    digest = hashlib.sha256()
+    for name in SOURCES:
+        with open(os.path.join(web_dir, name), encoding="utf-8") as f:
+            digest.update(name.encode("utf-8") + b"\0" + f.read().replace("\r\n", "\n").encode("utf-8") + b"\0")
+    return digest.hexdigest()
+
+
+def header(web_dir=WEB_DIR):
+    return f"/* built by launcher/build_css.py from {', '.join(SOURCES)}, sources {sources_hash(web_dir)} */"
+
+
+def main(argv):
+    tailwind = argv[1] if len(argv) > 1 else "tailwindcss"
+    if os.path.dirname(tailwind):
+        # a path, relative to where the command was typed; the CLI itself runs in web/
+        tailwind = os.path.abspath(tailwind)
+    built = OUTPUT + ".tmp"
+    command = [tailwind, "-i", os.path.join(WEB_DIR, "tailwind.css"), "-o", built, "--minify"]
+    try:
+        subprocess.run(command, check=True, cwd=WEB_DIR)
+    except (OSError, subprocess.CalledProcessError) as e:
+        sys.exit(f"Tailwind failed: {e}\nGive the path to the standalone CLI: py launcher/build_css.py <tailwindcss>")
+    with open(built, encoding="utf-8") as f:
+        css = f.read()
+    os.remove(built)
+    with open(OUTPUT, "w", encoding="utf-8", newline="\n") as f:
+        f.write(header() + "\n" + css.rstrip("\n") + "\n")
+    print(f"Wrote {OUTPUT}, {len(css) // 1024} KB")
+
+
+if __name__ == "__main__":
+    main(sys.argv)
```
