# v1.4 Part 3: Finding the server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** **Hľadať servery** in the launcher's client form lists every pyhome server on the local network with its name, address, TLS and certificate fingerprint; picking one fills the form, and a client made from a server on another computer gets that server's `ca.crt`, checked against the fingerprint. The server never says its token.

**Architecture:** `server/handlers/discovery.py` is an asyncio datagram endpoint on `DISCOVERY_PORT` (50002) started by `server/app.py` next to the TCP listener and the dashboard; it answers a well formed request with a fixed public answer, at most 20 a second. `launcher/discovery.py` sends the request to each network's /24 broadcast, `255.255.255.255` and `127.0.0.1`, collects answers for a second and validates them field by field; `fetch_ca()` downloads `/ca.crt` from a server's dashboard and checks its SHA-256. `launcher/api.py` gains `find_servers()` and fetches the `ca.crt` in `save_client()` for a picked server that is not this checkout's. The page shows the list in the client sheet.

**Tech Stack:** Python 3.10+ standard library (`socket`, `asyncio`, `ssl`, `urllib`), plain JavaScript. pytest; Playwright for the page check.

**Spec:** `docs/v1.4-spec.md`, section "Part 3: Finding the server", as amended in Task 4.

**Verified:** built in a scratch checkout first: 343 tests pass. A real server with TLS and a token answered a request on loopback with exactly its public fields; a client made through the api from the found server, as a server elsewhere, downloaded `ca.crt`, matched the fingerprint and connected `(TLS)`; a ca.crt with another fingerprint was refused; `DISCOVERY: false` stayed silent; a taken port gave a warning and the server ran on. In Chromium against the real api: the server printed `Discovery answering on UDP port 50002`, **Hľadať servery** found it through the broadcast at its network address, marked "na tomto počítači", picking it filled the address, ticked the token and TLS, and the new client connected `(TLS)`.

## Global Constraints

- The answer holds only: type, version, id, name, port, web_port, tls, fingerprint, token_required. Never the token.
- Requests and answers over 2 KB, or not of the exact shape, are ignored on both sides.
- The server answers at most 20 requests a second.
- Discovery never stops the server: off by `DISCOVERY: false`, a warning when its port is taken.
- A downloaded `ca.crt` is kept only when its SHA-256 equals the announced fingerprint; the download goes through no proxy.
- End to end servers answer on a free UDP port, never 50002.
- Work happens on branch `claude/admiring-ptolemy-mfwswb`.

```diff
+"""Answers who is there: a UDP datagram asks, the server says who it is and how to reach it.
+
+The launcher's Find servers broadcasts {"type": "pyhome-discover", "version": 1}
+and every server that hears it answers the sender with its id, name, ports,
+whether it has TLS and the fingerprint of its ca.crt. Never the token, and
+nothing else that is secret: anyone on the network may ask. The address is
+the one the answer comes from, so the server never has to know its own.
+"""
+import asyncio
+import collections
+import json
+import socket
+import time
+
+from shared.config import get_config
+from handlers.tls import TLSConfigError, ca_file, fingerprint, tls_files
+
+DEFAULT_PORT = 50002
+REQUEST = "pyhome-discover"
+ANSWER = "pyhome-server"
+VERSION = 1
+# a request larger than this is not one, and is not read further
+MAX_SIZE = 2048
+# answers per second at most, so the server cannot be used to flood the network
+RATE = 20
+
+
+def discovery_port():
+    """The UDP port to answer on, or None when DISCOVERY is false."""
+    if get_config("DISCOVERY", True) is False:
+        return None
+    return get_config("DISCOVERY_PORT", DEFAULT_PORT)
+
+
+def server_answer():
+    """What the server says about itself. Public on purpose: no token, nothing secret."""
+    try:
+        tls = tls_files() is not None
+        ca = ca_file()
+    except TLSConfigError:
+        tls, ca = False, None
+    return {
+        "type": ANSWER,
+        "version": VERSION,
+        "id": get_config("ID"),
+        "name": get_config("NAME"),
+        "port": get_config("PORT"),
+        "web_port": get_config("WEB_PORT", 50001),
+        "tls": tls,
+        "fingerprint": fingerprint(ca) if ca else None,
+        "token_required": bool(get_config("TOKEN")),
+    }
+
+
+def is_request(data):
+    """True when data is a discovery request: small, JSON, the right type."""
+    if len(data) > MAX_SIZE:
+        return False
+    try:
+        message = json.loads(data.decode("utf-8"))
+    except (UnicodeDecodeError, ValueError):
+        return False
+    return isinstance(message, dict) and message.get("type") == REQUEST and isinstance(message.get("version"), int)
+
+
+class DiscoveryProtocol(asyncio.DatagramProtocol):
+    def __init__(self, answer, rate=RATE):
+        self.answer = json.dumps(answer, ensure_ascii=False).encode("utf-8")
+        self.rate = rate
+        # when the answers of the last second went out
+        self.sent = collections.deque()
+        self.transport = None
+
+    def connection_made(self, transport):
+        self.transport = transport
+
+    def datagram_received(self, data, addr):
+        if not is_request(data):
+            return
+        now = time.monotonic()
+        while self.sent and now - self.sent[0] >= 1:
+            self.sent.popleft()
+        if len(self.sent) >= self.rate:
+            return
+        self.sent.append(now)
+        self.transport.sendto(self.answer, addr)
+
+    def error_received(self, exc):
+        # an asker that is gone again; nothing to do
+        pass
+
+
+def discovery_socket(host, port):
+    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
+    # windows reports an asker that went away as an error on the next read, which would
+    # end reading altogether; this turns that report off
+    if hasattr(socket, "SIO_UDP_CONNRESET"):
+        sock.ioctl(socket.SIO_UDP_CONNRESET, False)
+    try:
+        sock.bind((host, port))
+    except OSError:
+        sock.close()
+        raise
+    return sock
+
+
+async def start_discovery(port):
+    """Answer on UDP port. Returns the transport to close. OSError when the port cannot be used."""
+    loop = asyncio.get_running_loop()
+    sock = discovery_socket(get_config("HOST", "0.0.0.0"), port)
+    transport, _ = await loop.create_datagram_endpoint(lambda: DiscoveryProtocol(server_answer()), sock=sock)
+    return transport
```

```diff
+    if len(data) > MAX_SIZE:

+    if not isinstance(answer["tls"], bool) or not isinstance(answer["token_required"], bool):
+        return None
+    if answer["tls"] != isinstance(answer["fingerprint"], str):

+def find_servers(port=DEFAULT_PORT, timeout=1.0, hosts=None):
+    """Every server that answers within timeout seconds, one entry per server.
+
+    Each entry is the answer plus "addresses" it answered from and "host",
+    the one to use: a network address over 127.0.0.1, so a config made with
+    it also works on another computer.
+    """
+    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
+    try:
+        sock.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1)
+        if hasattr(socket, "SIO_UDP_CONNRESET"):
+            # windows: an address nobody listens on would end the reading below
+            sock.ioctl(socket.SIO_UDP_CONNRESET, False)
+        sock.bind(("0.0.0.0", 0))
+        for host in hosts or targets():

+                sock.sendto(REQUEST, (host, port))
+            except OSError:

+                pass

+        deadline = time.monotonic() + timeout
+        while (left := deadline - time.monotonic()) > 0:
+            sock.settimeout(left)
+            try:
+                data, (address, _) = sock.recvfrom(65535)
+            except socket.timeout:
+                break
+            except OSError:
+                continue
+            answer = parse_answer(data)
+            if answer is None:
+                continue
+            key = (answer["id"], answer["port"], answer["fingerprint"])
+            entry = found.setdefault(key, {**answer, "addresses": []})
+            if address not in entry["addresses"]:

+    return sorted(servers, key=lambda s: (s["name"].lower(), s["host"]))

+    """SHA-256 of a PEM certificate as AB:CD:..., the same as the server and make_certs.py print."""
+    return ":".join(f"{b:02X}" for b in hashlib.sha256(ssl.PEM_cert_to_DER_cert(pem)).digest())

+def fetch_ca(host, web_port, expected, timeout=5):
+    """The server's ca.crt from its dashboard, as PEM text, checked against the fingerprint expected.
+
+    The download itself cannot be verified, that is what the authority is for;
+    the fingerprint is the check. Not through any proxy: the server is at home.
+    """
+    context = ssl.create_default_context()
+    context.check_hostname = False
+    context.verify_mode = ssl.CERT_NONE
+    opener = urllib.request.build_opener(urllib.request.ProxyHandler({}), urllib.request.HTTPSHandler(context=context))
+    try:
+        with opener.open(f"https://{host}:{web_port}/ca.crt", timeout=timeout) as response:
+            pem = response.read(CA_LIMIT).decode("ascii")
+        actual = ca_fingerprint(pem)
+    except (OSError, ValueError, UnicodeDecodeError) as e:
+        raise CAError(f"ca.crt sa nedá stiahnuť zo servera {host}:{web_port}: {e}") from e
+    if actual != expected:
+        raise CAError("ca.crt zo servera nemá odtlačok, ktorý server ohlásil. Neukladám ho.")
+    return pem
```
