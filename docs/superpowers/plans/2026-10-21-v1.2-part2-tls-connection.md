# v1.2 Part 2: TLS on the client connection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With `TLS_CERT` and `TLS_KEY` on the server and `TLS_CA` on a client, the connection between them is TLS: the token and every message are unreadable on the wire. Every way the two sides can disagree ends in a readable line on the client; a rejected certificate or a broken `TLS_CA` stops retrying like a refused token. Without TLS settings both sides work as in 1.1, with a warning each.

**Architecture:** A new `server/handlers/tls.py` builds the server's `SSLContext` from `TLS_CERT`/`TLS_KEY` (paths via Part 1's `get_config_file`), refuses to start on a bad pair, and reports at startup (on, valid until, expiring, expired, or off). `server_handler.start_server_async` passes the context to `asyncio.start_server(ssl=...)`; nothing else on the server changes, `reader`/`writer` hide TLS. On the client, `connection_handler` gains `tls_context()` (trusts `TLS_CA`, chain verified, `check_hostname` off), `open_connection(context)` that turns TLS failures into `TLSRefused` (stop retrying) or a `ConnectionError` with a hint (retry), a `TLSRefused` branch in the connect loop next to `AccessDenied`, a hint for a plain hello hung up by a TLS server, and `Connection.tls`.

**Tech Stack:** Python 3.10+, `ssl` and asyncio from the standard library on the client; `cryptography` on the server only, to read the certificate's end date. Tests are plain scripts run by `py tests/run_all.py`.

**Spec:** `docs/v1.2-spec.md`, section "Part 2: TLS on the client connection".

**Verified:** this plan's code was built and run once in a scratch checkout before it was written down. Every test file passes, `test_launcher.py` included (with a Python that has `tkinter`). The end to end test puts a recording proxy between a real client and a real server: with TLS the token is not on the wire and the first byte is a TLS record; the control without TLS shows the same proxy does see the token.

## Global Constraints

- The client stays on the standard library.
- Client context: `ssl.create_default_context(cafile=TLS_CA)`, `check_hostname = False`, so the chain is verified against this house's authority and nothing else. The reason is written next to the line.
- `ssl.SSLCertVerificationError` is an `OSError`: it is caught before any `except OSError`.
- `ssl_handshake_timeout` is passed only together with `ssl=`, asyncio refuses it otherwise.
- A refused connection (server down) is never reported as a TLS problem.
- A server with a `TLS_CERT` or `TLS_KEY` it cannot use exits at startup with the reason, through the existing fatal branch.
- Without TLS settings nothing changes but one warning per side.
- The protocol does not change.
- Match the surrounding code: lowercase `#` comments that say why, short docstrings, no type annotations.
- Work happens on branch `claude/admiring-ptolemy-mfwswb`.

```python
"""TLS for the server: the context from TLS_CERT and TLS_KEY, and what to say about it at startup."""
import datetime
import ssl

from cryptography import x509
from shared.config import get_config_file

# a certificate this close to its end gets a warning at every start
EXPIRY_WARNING_DAYS = 30


class TLSConfigError(Exception):
    """TLS_CERT or TLS_KEY is set but cannot be used. The server must not start without it."""


def tls_files():
    """(cert path, key path), or None when the server has no TLS. TLSConfigError when only one is set."""
    cert, key = get_config_file("TLS_CERT"), get_config_file("TLS_KEY")
    if cert is None and key is None:
        return None
    if cert is None or key is None:
        missing = "TLS_CERT" if cert is None else "TLS_KEY"
        raise TLSConfigError(f"{missing} is empty, TLS needs both TLS_CERT and TLS_KEY")
    return cert, key


def server_context():
    """The SSLContext for the client listener, or None without TLS. TLSConfigError when it cannot be built."""
    files = tls_files()
    if files is None:
        return None
    cert, key = files
    context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
    try:
        context.load_cert_chain(cert, key)
    except FileNotFoundError as e:
        raise TLSConfigError(f"TLS file not found: {e.filename}") from e
    except ssl.SSLError as e:
        # a broken file, or a key that belongs to another certificate
        raise TLSConfigError(f"TLS_CERT and TLS_KEY cannot be used together: {e.reason or e}") from e
    return context


def cert_expiry(path):
    """When the certificate at path stops being valid, as an aware UTC datetime."""
    with open(path, "rb") as f:
        return x509.load_pem_x509_certificate(f.read()).not_valid_after_utc


def startup_lines(now=None):
    """[(is_warning, text)] the server prints about TLS when it starts."""
    files = tls_files()
    if files is None:
        return [(True, "No TLS_CERT set, the token and every message cross the network in plain text")]

    expiry = cert_expiry(files[0])
    lines = [(False, f"TLS on, certificate valid until {expiry.date().isoformat()}")]
    left = expiry - (now or datetime.datetime.now(datetime.timezone.utc))
    renew = "renew it with py server/make_certs.py"
    if left <= datetime.timedelta(0):
        # clients will refuse it, say so before they do
        lines.append((True, f"The TLS certificate has expired, {renew}"))
    elif left <= datetime.timedelta(days=EXPIRY_WARNING_DAYS):
        lines.append((True, f"The TLS certificate ends in {left.days} days, {renew}"))
    return lines
```

from handlers import connection_handler  # noqa: E402
from handlers.commands import reconnect  # noqa: E402
from helpers import run_tests  # noqa: E402

WELCOME = {"type": "welcome", "id": "s", "name": "Server", "role": "server",
           "version": "test", "host": "127.0.0.1", "port": 1}


class FakeServer:
    """Answers every hello with a welcome, over TLS when given a context."""

    def __init__(self, context=None):
        self.context = context
        self.hellos = []
        self.writers = []

    async def handle(self, reader, writer):
        self.writers.append(writer)
        try:
            hello = await read_message(reader)
        except Exception:
            # what a plain server makes of a TLS hello
            writer.close()
            return
        if hello is None:
            writer.close()
            return
        self.hellos.append(hello)
        reply = dict(WELCOME)
        await send_message(writer, reply.pop("type"), **reply)
        await reader.read()
        writer.close()

    async def start(self):
        self.server = await asyncio.start_server(self.handle, "127.0.0.1", 0, ssl=self.context)
        return self.server.sockets[0].getsockname()[1]

    async def stop(self):
        for writer in self.writers:
            writer.close()
        self.server.close()
        await self.server.wait_closed()


def certs(tmp, name="certs"):
    """A fresh authority and server certificate in tmp/name. Returns the server's SSLContext."""
    folder = os.path.join(tmp, name)

    context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
    context.load_cert_chain(os.path.join(folder, "server.crt"), os.path.join(folder, "server.key"))
    return context

def reset():
    c = connection_handler.connection
    c.connected = False
    c.reader = None
    c.writer = None
    c.server_info = {}
    c.auto_reconnect = False
    c.tls = False

async def until(check, seconds=5):
    for _ in range(int(seconds * 20)):
        if check():
            return
        await asyncio.sleep(0.05)
    raise AssertionError("condition never became true")


async def hang_up():
    writer = connection_handler.connection.detach()
    if writer:
        writer.close()


def quietly(coroutine):
    with contextlib.redirect_stdout(io.StringIO()) as out:
        result = asyncio.run(coroutine)
    return result, out.getvalue()


def expect(coroutine, error):
    """The message of the error coroutine raises, run quietly."""
    async def wrapped():
        try:
            await coroutine
        except error as e:
            return str(e)
        raise AssertionError(f"expected {error.__name__}")
    return quietly(wrapped())[0]

def test_untrusted_certificate_stops_retrying(tmp):
    reset()
    server_context = certs(tmp, "house")
    certs(tmp, "other")
    attempts = []
    # a failed TLS handshake never reaches the server's handler, count on the client
    original = connection_handler.handshake

    async def counting():
        attempts.append(1)
        await original()

    async def scenario():
        server = FakeServer(server_context)
        use_client_config(tmp, await server.start(), TLS_CA="other/ca.crt")
        loop = asyncio.create_task(connection_handler.connect_to_server_async())
        await until(lambda: attempts)
        # well past the loop's one second idle tick
        await asyncio.sleep(2.5)
        loop.cancel()
        await server.stop()

    connection_handler.handshake = counting
    try:
        _, out = quietly(scenario())
    finally:
        connection_handler.handshake = original
    assert len(attempts) == 1, f"retried {len(attempts)} times with the same TLS_CA"
    assert connection_handler.connection.auto_reconnect is False
    assert "TLS refused" in out and "not trusted" in out and "reconnect" in out, out

class Tap:
    """A TCP proxy between a client and the server that keeps every byte the client sends."""

    def __init__(self, upstream_port):
        self.upstream_port = upstream_port
        self.port = free_port()
        self.seen = bytearray()
        self.lock = threading.Lock()
        self.listener = socket.create_server(("127.0.0.1", self.port))
        threading.Thread(target=self.accept, daemon=True).start()

    def accept(self):
        while True:
            try:
                client, _ = self.listener.accept()
            except OSError:
                return
            upstream = socket.create_connection(("127.0.0.1", self.upstream_port))
            threading.Thread(target=self.pump, args=(client, upstream, True), daemon=True).start()
            threading.Thread(target=self.pump, args=(upstream, client, False), daemon=True).start()

    def pump(self, source, target, record):
        try:
            while data := source.recv(65536):
                if record:
                    with self.lock:
                        self.seen += data
                target.sendall(data)
        except OSError:
            pass
        finally:
            for s in (source, target):
                try:
                    s.shutdown(socket.SHUT_RDWR)
                except OSError:
                    pass

    def wire(self):
        with self.lock:
            return bytes(self.seen)

    def close(self):
        self.listener.close()
