# v1.4.1 specification

**Theme:** a new look for the launcher.

The design made in Claude Design, carried into the theme tokens and the page; no change to what the launcher does.

## Scope

**In**

1. Updated theme tokens in `launcher/web/tailwind.css` to match the new design from Claude Design
2. No functional changes to the launcher

**Out, and why**

| Not doing | Reason |
| --- | --- |
| Changes to `index.html` or `app.js` | The design is carried through theme tokens only; the markup and logic stay the same |
| New features or behaviour | This version is a visual refresh only |

## Design

The new design keeps the monochrome dark glass foundation but refines the color tokens, spacing, and typography to match the approved Claude Design mockup. All changes are in the `@theme` block and `@layer components` of `launcher/web/tailwind.css`.

Key changes from v1.4:

- Refined glass colors with adjusted opacity for better depth
- Updated accent color and its variants
- Adjusted blob colors for the background gradient
- Refined component styles (buttons, inputs, sidebar items)
- Updated ANSI color mappings to match the new palette

## Architecture

No architectural changes. The launcher remains:
- `launcher.pyw` opens the pywebview window
- `launcher/api.py` exposes backend methods to the page
- `launcher/web/tailwind.css` defines theme tokens, built to `launcher.css` by `launcher/build_css.py`
- `launcher/web/index.html` and `app.js` use the built CSS

## Implementation

### 1. Update theme tokens in `launcher/web/tailwind.css`

Replace the `@theme` block and `@layer components` with the new design tokens from Claude Design. The exact values come from the design artifact.

### 2. Rebuild CSS

Run `launcher/build_css.py` with the Tailwind CLI to generate the updated `launcher.css`.

### 3. Verify

- Open the launcher and confirm the new look matches the design
- Run the test suite to ensure no regressions

## Tests

Existing tests in `tests/` cover the launcher's backend (`launcher/api.py` and below). No new tests needed since this is a visual-only change.

The CSS build test (`tests/test_launcher_css.py`) will verify the built `launcher.css` is current after the token changes.

## Done when

- The launcher window matches the new Claude Design mockup
- All existing tests pass
- The built `launcher.css` is committed and up to date with `tailwind.css`

## Version

`VERSION` in both example configs becomes `1.4.1`. `docs/versions/v1.4.1.md` is written when the version is finished, and its row in the README roadmap is struck.
